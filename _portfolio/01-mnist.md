## Project Overview

MNIST 데이터셋을 활용하여 손글씨 숫자를 분류하는
CNN 모델을 개발하고 성능을 개선하였다.

## Objective

- 이미지 분류 모델의 성능 향상
- 다양한 모델 구조 및 학습 방법 비교

## Technologies

- Python
- TensorFlow / Keras
- CNN
- Data Augmentation

## Methodology

- Convolution Layer 구성
- Global Average Pooling 적용
- Data Augmentation
- Early Stopping
- Learning Rate Scheduling

## Results

| Metric | Result |
| --- | --- |
| Kaggle Accuracy | 0.99675 |

## Key Takeaways

모델 구조와 데이터 증강 방법에 따른
분류 성능의 변화를 확인하였다.
